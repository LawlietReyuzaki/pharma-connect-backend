🚀 What you’ll ship in the MVP

Landing page (store grid + appointment booking + Urdu chatbot widget with voice).

Chatbot API with basic medical guardrails + optional LLM (OpenAI) fallback.

Appointments (slots, booking, status) + video room via embedded Jitsi (free).

Store (medicine CRUD, cart → order) + delivery statuses.

Admin dashboard (appointments, medicines, orders, delivery).

Share links (tokenized URLs for appointment, order, video room).

One-click bootstrap (DB init + seed admin/doctor/medicines).

Tech choices are Replit-friendly and simple:

Backend: Flask + SQLite + SQLAlchemy

Frontend: Flask templates + vanilla JS (keeps one process on Replit)

Auth: JWT (simple)

Voice: Web Speech API (STT & TTS) for Urdu (ur-PK)

Video: Jitsi iFrame (no server needed)

8) Auth service (JWT)
services/auth.py
import os, time, jwt, hashlib
from models import User

SECRET = os.getenv("JWT_SECRET", "devsecret")

def phash(pw): return hashlib.sha256(pw.encode()).hexdigest()

def create_token(user):
    payload = {"sub": user.id, "role": user.role, "exp": int(time.time()) + 60*60*12}
    return jwt.encode(payload, SECRET, algorithm="HS256")

def verify_user(email, password):
    u = User.query.filter_by(email=email).first()
    if not u: return None
    return u if u.password_hash == phash(password) else None

routes/auth_routes.py
from flask import Blueprint, request, jsonify
from services.auth import verify_user, create_token

bp = Blueprint("auth", __name__)

@bp.post("/login")
def login():
    data = request.json or {}
    u = verify_user(data.get("email",""), data.get("password",""))
    if not u: return jsonify({"error":"invalid credentials"}), 401
    return jsonify({"token": create_token(u), "user": {"id":u.id,"name":u.name,"role":u.role}})

9) Chatbot with medical guardrails (+Urdu)
services/chatbot.py
import os, re
from datetime import datetime
from openai import OpenAI

client = None
if os.getenv("OPENAI_API_KEY"):
    client = OpenAI()

RED_FLAGS = [
    r"chest pain", r"سانس.*میں دقت", r"respiratory distress", r"stroke", r"بیہوش", r"severe bleeding",
]

DISCLAIMER_UR = (
    "⚠️ یہ معلومات طبی مشورہ نہیں۔ ہنگامی صورتحال میں مقامی ایمرجنسی نمبر پر فوراً رابطہ کریں۔"
)

def needs_escalation(text: str) -> bool:
    t = text.lower()
    return any(re.search(p, t) for p in RED_FLAGS)

def reply(text: str, prefer_urdu=True) -> str:
    if needs_escalation(text):
        return f"{DISCLAIMER_UR}\nیہ علامات سنگین ہو سکتی ہیں۔ براہِ کرم فوراً ڈاکٹر سے رابطہ کریں یا ایمرجنسی جائیں۔"

    # Lightweight offline fallback
    if not client:
        return "میں سمجھ گیا/گئی۔ مزید درست رہنمائی کے لیے آپ اپنی علامات، دورانیہ، اور موجودہ دوا لکھیں۔ " + DISCLAIMER_UR

    sys = "You are a medical safety assistant. Provide general guidance only, not diagnosis. Keep it concise. If unsure, recommend seeing a doctor in-person."
    if prefer_urdu: sys += " Reply in Urdu."

    resp = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role":"system","content":sys},{"role":"user","content":text}],
        temperature=0.3,
    )
    return resp.choices[0].message.content.strip()

static/js/voice.js (Urdu STT + TTS)
const SR = window.SpeechRecognition || window.webkitSpeechRecognition;
const synth = window.speechSynthesis;

export async function speakUrdu(text) {
  const u = new SpeechSynthesisUtterance(text);
  u.lang = 'ur-PK';
  synth.speak(u);
}

export function listenUrdu(onResult) {
  if(!SR) return alert('SpeechRecognition not supported in this browser');
  const rec = new SR(); rec.lang = 'ur-PK'; rec.interimResults = false;
  rec.onresult = e => onResult(e.results[0][0].transcript);
  rec.start();
  return rec;
}

import hashlib, time

def make_token(kind:str, id:int) -> str:
    raw = f"{kind}:{id}:{int(time.time()/3600)}"  # rotates hourly
    return hashlib.md5(raw.encode()).hexdigest()[:10]
