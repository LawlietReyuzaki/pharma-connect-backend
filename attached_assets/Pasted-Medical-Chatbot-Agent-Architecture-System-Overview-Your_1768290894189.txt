🤖 Agent Breakdown
1. Query Classifier (Intent Agent)
File: query_classifier.py
Purpose: Understands what the user is asking for
Capabilities:

Detects query type (medication/disease/symptom)
Extracts medical entities (medicine names, diseases)
Determines which data sources to use
Decides if images should be fetched

Example:
pythonfrom services.query_classifier import QueryClassifier

classifier = QueryClassifier()
result = classifier.classify("Panadol for fever")

# Result:
{
    'type': 'medication_specific',
    'confidence': 0.9,
    'entities': {
        'medications': ['panadol'],
        'diseases': ['fever']
    },
    'should_search_db': True,
    'should_fetch_images': True,
    'image_subject': 'panadol'
}

2. Smart RAG Orchestrator (Master Agent)
File: smart_rag_orchestrator.py
Purpose: Coordinates all retrieval operations
Capabilities:

Routes queries to appropriate agents
Enforces database-first policy
Validates retrieved data
Builds context for AI
Prevents irrelevant content

Example:
pythonfrom services.smart_rag_orchestrator import smart_retrieve

result = smart_retrieve("medicine for headache", "en")

# Result:
{
    'medications': [list of medicines from DB],
    'wiki_context': None,  # DB had results, no Wiki needed
    'images': [validated medicine images],
    'context_type': 'database',
    'should_show_images': True
}

5. Image Validation Agent
File: query_classifier.py (functions)
Purpose: Validates medication images before display
Capabilities:

Checks image exists in database
Validates local path (no external URLs)
Ensures filename matches medication
Blocks irrelevant keywords

Rules:
python✅ ALLOWED:
- panadol.jpg (matches "Panadol" medicine)
- aspirin_500mg.png (matches "Aspirin 500mg")

❌ BLOCKED:
- fever_anatomy.jpg (disease image)
- body_diagram.png (anatomy)
- wikipedia_logo.svg (logo)
- external-url.com/image.jpg (external URL)

6. AI Response Generator
File: chatbot_with_smart_rag.py
Purpose: Generates natural language responses using Gemini
Capabilities:

Builds context from all agents
Applies safety guardrails
Formats medicine information
Adds medical disclaimers
Supports English and Urdu

│
└─ Output: medications=[...], images=[...], context_type="database"

Step 3: AI Response Generator
├─ Builds context from DB data
├─ Generates response via Gemini
└─ Adds medical disclaimer

Intelligent Routing

Quality Control

Performance

Safety

Medical guardrails throughout
No irrelevant content leaks through


Extensibility

Easy to add new agents (e.g., drug interaction checker)
