🔍 New Features
1. Pattern Recognition
The agent now recognizes these patterns:
python"what are symptoms of [X]" → Extracts X
"medicine for [Y]" → Extracts Y
"treatment for [Z]" → Extracts Z
"what is [W]" → Extracts W
2. Dual Search
pythonSingle query now triggers:
├─ Wikipedia search (with extracted keyword)
└─ Medicine catalog search (automatic)
3. Smart Entity Recognition
pythonRecognizes:
- Known diseases (diabetes, hypertension, etc.)
- Symptoms (fever, pain, cough, etc.)
- Medicine names (paracetamol, aspirin, etc.)
4. Confidence Scoring
pythonHigh confidence (0.8-1.0) → Pattern match
Medium confidence (0.5-0.7) → Entity match
Low confidence (<0.5) → Falls back to old method

Solution: Add the pattern to the agent. Edit wikipedia_medical_agent.py:
python# Add to DISEASE_NAMES list (line ~40)
DISEASE_NAMES = [
    'diabetes', 'hypertension', 'your_disease', ...
]

# Or add to QUESTION_PATTERNS (line ~60)
'symptoms': [
    r'your custom pattern here',
    ...
]

Check:
pythonfrom services.medicine_rag import search_medicines, search_medicines_for_condition

Matching names
Matching descriptions
Matching categories
