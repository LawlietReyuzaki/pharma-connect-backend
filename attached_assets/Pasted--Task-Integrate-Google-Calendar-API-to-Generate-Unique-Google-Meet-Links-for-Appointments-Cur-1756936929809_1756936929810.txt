### Task: Integrate Google Calendar API to Generate Unique Google Meet Links for Appointments

Current Issue:  
- The app currently saves either invalid random Google Meet URLs or the generic `https://meet.google.com/new` link.  
- This does not guarantee a unique persistent meeting per appointment.

---

### Goal:  
- Use **Google Calendar API** to create a Calendar Event when an appointment is booked.  
- Enable Google Meet integration so a **real Meet link** is generated by Google.  
- Save this Meet link in the `appointments` table.  
- Ensure both doctor and patient dashboards show the same link.

---

### Steps to Implement:

1. **Setup Google API**
   - Create a Google Cloud Project.
   - Enable **Google Calendar API**.
   - Create **OAuth2 credentials** or a **Service Account**.
   - Download `credentials.json` and add it to the backend securely (do not commit to repo).

2. **Backend Integration**
   - Install required libraries:
     ```bash
     pip install google-api-python-client google-auth-httplib2 google-auth-oauthlib
     ```
   - Create a utility function `create_google_meet_event(appointment_data)`:
     - Authenticates using OAuth/Service Account.
     - Calls `calendar.events.insert` with:
       ```json
       {
         "summary": "Doctor Appointment",
         "start": { "dateTime": "2025-09-05T09:00:00", "timeZone": "Asia/Karachi" },
         "end": { "dateTime": "2025-09-05T09:30:00", "timeZone": "Asia/Karachi" },
         "conferenceData": {
           "createRequest": {
             "requestId": "appointment-123",
             "conferenceSolutionKey": { "type": "hangoutsMeet" }
           }
         },
         "attendees": [
           { "email": "doctor@example.com" },
           { "email": "patient@example.com" }
         ]
       }
       ```
     - Extract the returned Meet link:
       ```python
       event["hangoutLink"]
       ```

3. **Database Update**
   - Add column `google_meet_link` to `appointments` table if not already present.
   - Save the `hangoutLink` when the event is successfully created.

4. **Frontend Update**
   - In both doctor and patient dashboards, replace the Join button href with the DB `google_meet_link`.

5. **Error Handling**
   - If Google API call fails, fallback to `https://meet.google.com/new`.
   - Log errors for debugging.

---

### Expected Result:
- When an appointment is created:
  - A Google Calendar Event is automatically created.
  - A **unique Meet link** is generated.
  - Both doctor and patient see the same working link.
  - Clicking "Join Meeting" takes them to a real Google Meet room.

✅ This ensures each appointment has its own secure video session.
