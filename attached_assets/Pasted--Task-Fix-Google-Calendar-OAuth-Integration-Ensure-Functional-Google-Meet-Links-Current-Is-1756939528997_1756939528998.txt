# Task: Fix Google Calendar OAuth Integration & Ensure Functional Google Meet Links

## Current Issues
- Doctor dashboard shows **“Unable to check Google Calendar status”**.  
- API calls return **401 Unauthorized** (invalid/missing tokens).  
- Calendar is not updated after booking.  
- Meet links are incorrect (either broken or generic).  
- Doctor’s available slots do not load from Google Calendar.  

---

## Goal
- Implement **per-doctor OAuth integration** with Google Calendar.  
- Each doctor signs in once, granting access to their personal Google Calendar.  
- Store **OAuth access_token + refresh_token** per doctor in DB.  
- When an appointment is booked:
  - A **real Google Calendar event** is created.  
  - A **Google Meet link** is auto-generated by API.  
  - Link is stored in `appointments` table.  
  - Both doctor and patient dashboards display the **same functional Meet link**.  
  - Slots are fetched dynamically from Google Calendar availability.  

---

## Steps to Implement

### 1. Google Cloud Setup
1. Create a **Google Cloud Project**.  
2. Enable **Google Calendar API**.  
3. Create **OAuth Client ID** (Web App type).  
4. Set Redirect URI → `https://yourapp.com/auth/google/callback`.  
5. Store `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` in environment variables.  

---

### 2. OAuth Flow per Doctor
1. Add button: **“Connect Google Calendar”**.  
2. Redirect doctor to Google OAuth consent screen with scope:  

https://www.googleapis.com/auth/calendar

3. After consent, Google redirects back with code.  
4. Exchange code → get `access_token` + `refresh_token`.  
5. Save tokens in DB → `(doctor_id, access_token, refresh_token, expiry)`.  

---

### 3. Check Calendar Status
- Create endpoint:  
GET /api/doctors/{id}/calendar/status

- Use doctor’s tokens to call:
```python
service = build("calendar", "v3", credentials=creds)
service.calendarList().get(calendarId="primary").execute()


If success → status ✅ Connected.

If 401 → doctor must re-authenticate. 

4. Create Appointment Event with Meet Link

On booking:

event = {

created_event = service.events().insert(

meet_link = created_event["hangoutLink"]


Save meet_link to appointments.google_meet_link.

Use Freebusy API:

  "timeMin": start_of_day,

Mark busy slots.

Show free slots in doctor dashboard.

6. Frontend Fix

Update Join button → use appointments.google_meet_link.

Update doctor dashboard → show real Google availability.

If token expired → show reconnect prompt.

7. Error Handling & Fallback

If API fails → log error & notify doctor.

Optional fallback: https://meet.google.com/new.

Refresh tokens automatically before expiry.
